# DCAF15 monomer simulations

Coarse-grained molecular dynamics of single-chain (monomer) **α-synuclein
(aSyn)** together with **DCAF15**, using the
[CALVADOS](https://github.com/KULL-Centre/CALVADOS) force field. This
repository accompanies *(manuscript in preparation)* and covers the
monomer/pairwise simulations and their analysis; the companion fibril
simulations are published in a separate repository.

This repository is being populated in stages. **Currently available: the
analysis notebook and the simulation setup/launch scripts**, covering the
wild-type DCAF15 complex and three charge-neutralized DCAF15 surface variants
(4, 8 and 12 positively charged residues → Ala).

## Repository layout

```
notebooks/
  plots.ipynb          ← analysis + figure generation (Figs S3B, S3C, 3F, 3G, 3H)
scripts/
  prepare.py                      ← builds one replicate's CALVADOS config/components from ./input/
  submit.py                       ← submits one replicate as a Slurm job (cluster-specific; edit before reuse)
  submit_replicas.py              ← sets up + submits all replicas for a set of variant directories
  automated_variant_submission.py ← seeds new variant directories from an existing one
  input/
    idr.fasta                     ← aSyn sequence (shared across variants)
    domains.yaml                  ← DCAF15 folded-domain definitions (harmonic restraints)
    residues_CALVADOS3.csv        ← CALVADOS 3 residue-level force-field parameters
    dcaf15_base.pdb               ← wild-type DCAF15 structure
    dcaf15_pos4.pdb               ← 4 positively charged surface residues → Ala
    dcaf15_pos8.pdb                ← 8 positively charged surface residues → Ala
    dcaf15_pos12.pdb              ← 12 positively charged surface residues → Ala
data/
  residues_CALVADOS3.csv         ← CALVADOS 3 residue-level force-field parameters
  uniprot_variants/               ← simulation output, downloaded from cluster, not tracked in git
    base/   <1..10>/data/...      ← wild-type DCAF15
    pos4/   <1..10>/data/...      ← 4 positively charged surface residues → Ala
    pos8/   <1..10>/data/...      ← 8 positively charged surface residues → Ala
    pos12/  <1..10>/data/...      ← 12 positively charged surface residues → Ala
figures/                ← output figures, generated by the notebook
```

## `scripts/` — setting up and launching a replicate

For a given variant (e.g. `pos4`), each replicate is its own directory
containing a copy of `prepare.py`/`submit.py` and of `scripts/input/`
(renaming that variant's `dcaf15_<variant>.pdb` to `dcaf15.pdb`). From inside
a replicate directory:

```bash
python prepare.py --name_1 asyn --name_2 dcaf15   # writes config.yaml / components.yaml
python submit.py asyn dcaf15 <replica_number>      # renders and submits the Slurm job script
```

`submit_replicas.py` automates this across all replicas of a set of variant
directories, skipping any replica that already has output
(`data/asyn_dcaf15_asyn_dcaf15_cmap.npy`). `submit.py` is written for a
Slurm cluster with a `sbinlab_ib2` partition and a conda environment named
`dcaf`; edit the job-script template before reusing it elsewhere.

Requires the [CALVADOS](https://github.com/KULL-Centre/CALVADOS) Python
package (and OpenMM), plus [Jinja2](https://jinja.palletsprojects.com/), to run.

## `notebooks/plots.ipynb`

Analyzes single-chain aSyn + DCAF15 simulations — wild-type DCAF15 and three
charge-neutralized DCAF15 surface variants — and reproduces Figures S3B, S3C,
3F, 3G and 3H:

- center-of-mass (COM–COM) distance timeseries, the finite-size-corrected
  radial distribution function, and the second virial coefficient (B2)
- per-residue contact numbers, for both DCAF15 and aSyn
- average aSyn–DCAF15 contact maps, with the mutated residues marked

Each simulation replicate is expected under
`data/uniprot_variants/<variant>/<1..10>/data/`, containing:

| File | Description |
|---|---|
| `asyn_dcaf15_com_traj.dcd` + `asyn_dcaf15_com_top.pdb` | center-of-mass trajectory/topology for the aSyn–DCAF15 pair |
| `asyn_dcaf15_asyn_dcaf15_cmap.npy` | aSyn × DCAF15 contact map, shape (140, 600) |
| `asyn_dcaf15_dcaf15_rg.npy`, `asyn_dcaf15_asyn_rg.npy` | per-frame radius of gyration |
